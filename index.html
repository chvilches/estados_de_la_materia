SÓLIDO
Toca para ver más ✨
¿Qué es un sólido? Tiene forma y tamaño fijos. ¡No se escapa ni cambia solito!

Ejemplos: hielo, piedra, madera, juguetes, lápices 🖍️
💧
LÍQUIDO
Toca para ver más ✨
¿Qué es un líquido? No tiene forma propia: toma la forma del recipiente. ¡Se puede verter!

Ejemplos: agua, leche, jugo, aceite 🥛
💨
GASEOSO
Toca para ver más ✨
¿Qué es un gas? No tiene forma ni tamaño fijo. ¡Ocupa todo el espacio que encuentra!

Ejemplos: aire, vapor, humo, el oxígeno 🎈

🔄 Las Transformaciones Mágicas

🧊 ➡️ 💧

Fusión

El sólido se vuelve líquido. Ej.: el hielo se derrite al sol ☀️

💧 ➡️ 🧊

Solidificación

El líquido se vuelve sólido. Ej.: el agua en el freezer se hace hielo ❄️

💧 ➡️ 💨

Evaporación

El líquido se vuelve gas. Ej.: el agua hirviendo hace vapor ♨️

💨 ➡️ 💧

Condensación

El gas se vuelve líquido. Ej.: las gotitas en el vaso frío 🥤
